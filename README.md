# Incident Response Plan

## Descripción

Este repositorio presenta un proyecto académico enfocado en la **gestión y respuesta a incidentes de ciberseguridad**.

El proyecto tiene como objetivo mostrar el proceso que una organización puede seguir para identificar, analizar, contener y recuperar sus operaciones después de un incidente de seguridad.

## Objetivo

Desarrollar una propuesta estructurada de respuesta a incidentes que permita establecer responsabilidades, clasificar los incidentes y definir acciones para reducir su impacto.

## Temas incluidos

- Identificación de incidentes.
- Clasificación y priorización.
- Análisis del incidente.
- Línea de tiempo de eventos.
- Contención.
- Erradicación.
- Recuperación.
- Lecciones aprendidas.

## Clasificación de incidentes

Algunos de los incidentes considerados durante el proyecto fueron:

- Malware.
- Phishing.
- Acceso no autorizado.
- Fuga de información.
- Ransomware.

Los incidentes pueden clasificarse de acuerdo con su nivel de impacto y urgencia para determinar la prioridad de atención.
